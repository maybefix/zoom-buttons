# Zoom Button

This is a simple plugin for Obsidian (https://obsidian.md).

This plugin is used with [vslinko/obsidian-zoom](https://github.com/vslinko/obsidian-zoom) to add zoom buttons to the header section.

## Usage

1. Please install [vslinko/obsidian-zoom](https://github.com/vslinko/obsidian-zoom).
2. Please install this plugin.
3. Go to Settings > Community Plugins and enable Zoom and the Zoom Button (make sure Restricted Mode is not enabled).
4. Hover your cursor over the heading, or lightly tap on it if using a smartphone, and a “+” mark will appear.
5. Click (or tap) the “+” mark to zoom in on the heading.

## How to install

You cannot enable this plugin within Obsidian at this time. Please install it using [TfTHacker/obsidian42-brat: BRAT - Beta Reviewer&#39;s Auto-update Tool for Obsidian.](https://github.com/TfTHacker/obsidian42-brat).

To install manually, follow these steps:

- Download `main.js`, `manifest.json`, `styles.css` from the latest relaese and put them into `<vault>/.obsidian/plugins/zoom-button` folder.
